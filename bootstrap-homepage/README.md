# Bootstrap Home Page

Bài thực hành xây dựng trang chủ với Bootstrap 5.3.3, Font Awesome 6.5.2, Carousel, Flexbox và Bootstrap Form.

## Chạy thử
1. Giải nén dự án.
2. Mở `index.html` bằng trình duyệt.
3. Cần có kết nối Internet để tải Bootstrap, Font Awesome và ảnh trong carousel từ CDN.

## Thành phần có trong bài
- Navbar responsive có icon Font Awesome.
- Hero Carousel gồm 3 slide, nút chuyển slide và tự chạy.
- Khu vực chào mừng căn giữa bằng tiện ích Flexbox của Bootstrap.
- Ba thẻ dịch vụ responsive.
- Form liên hệ có kiểm tra dữ liệu ngay trên trình duyệt.
- Footer responsive và năm tự cập nhật.

Lưu ý: Form hiện chỉ minh họa giao diện và xác thực ở phía trình duyệt, chưa gửi dữ liệu đến máy chủ.
